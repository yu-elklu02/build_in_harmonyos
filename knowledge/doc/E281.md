# E281 — 资源型语音/音频 Conan 叶子包适配

> 对应文件：`../graph/E281.kv`

## 1. 知识主题

OHOS 平台上无 C/C++ 编译步骤的语音/音频资源型 Conan 叶子包的适配方法：conanfile.py 空 build() + 文件复制安装 + test_package 消费者视角资源完整性验证。

## 2. 适用范围

- Festival / espeak-ng 等语音数据包（diphone voice data）
- 音频包（sound themes、音频数据集）
- 字体包（font data）
- 图标包（icon themes）
- 固件 / 数据包（dictionary、locale 数据）

判定标准：tarball 只有数据文件（.scm/.group/COPYING 等），无 C/C++ 源码、无构建系统（Makefile/CMake/configure）、无上游测试框架。

## 3. 问题背景

festvox-kdlpc8k 1.4.0 是 Festival TTS 的美式英语男声双音子语音包（8 kHz，LPC）。tarball 仅含 4 个文件：

| 文件 | 大小 | 类型 |
|------|------|------|
| COPYING | 2.5K | ASCII 文本（CSTR Edinburgh 许可） |
| ked_diphone.scm | 10K | ASCII Scheme 脚本 |
| kddurtreeZ.scm | 35K | ASCII Scheme 脚本 |
| kedlpc8k.group | 2.9M | EST_File index 二进制索引 |

Conan 适配时若按常规编译流程处理会失败：conan-init 生成错误的 autotools 模板、L0 门禁要求 test() 调用 self.run()、strip_root 参数与 package() 路径不一致导致资源找不到。

## 4. 上游测试核验方法

解压上游 tarball 后逐项检查：

- README / test/ / tests/ / Makefile / CMakeLists.txt / configure / ctest / make check / examples / sample / demo / CI

本库核验结果：**全部不存在**。

上游测试：**0/0（N/A，上游无测试用例，已核验完整 tarball）**。0/0 表示上游确实没有测试，不是测试失败。

## 5. 资源型 Conan 包适配方法

```python
# conanfile.py 关键点
def source(self):
    get(self, **self.conan_data["sources"], strip_root=True)   # 移除 tarball 顶层目录

def build(self):
    apply_conandata_patches(self)   # 空补丁应用，满足 G1 门禁

def package(self):
    src = os.path.join(self.source_folder, "lib", "voices", "english", "ked_diphone")
    dst = os.path.join(self.package_folder, "share", "festival", "voices", "english", "ked_diphone")
    copy(self, "*", src, dst)        # 直接文件复制，无编译
```

**关键注意点**：
- `strip_root=True` 后 package() 路径必须同步去掉顶层目录（`festival/`），否则资源找不到
- `requirements()` 和 `tool_requires()` 必须为空（叶子库无第三方 Conan 前置）
- Festival 运行时是可选验证工具，**不得**因此加入 Conan requirements

## 6. test_package 消费者验证方法

test() 必须通过 `self.run()` 调用真实测试脚本（满足 L0d 门禁，防止 stub_test_method）：

```python
def test(self):
    pkg_folder = self.dependencies["festvox-kdlpc8k"].package_folder
    voice_dir = os.path.join(pkg_folder, "share", "festival", "voices", "english", "ked_diphone")
    script = os.path.join(self.source_folder, "test_resources.sh")
    self.run(f"sh {shlex.quote(script)} {shlex.quote(voice_dir)}")
```

OHOS sandbox 无法 fork 子进程（OOM）时，可先用 Python 内联断言验证，但最终必须恢复 self.run() 结构以满足远端 L0 门禁。

## 7. 真实验证命令

## 9. 限制条件

- 19/19 是**新增消费者资源断言**，不是上游测试通过率
- `published` 只能表示已完成 Conan 制品 upload；本 PR 状态保持 `built`
- OHOS sandbox 的 fork/OOM 限制可能导致 shell 子进程失败，需用 Python 内联或简单 shell built-in 缓解

## 10. 禁止误用方式

- ❌ 把新增 test_package 断言写成上游测试通过率
- ❌ 因 Festival smoke 依赖就把 Festival 加入 Conan requirements()
- ❌ 未 upload 就写 `status: published`
- ❌ `strip_root=False` 却用带顶层目录的 source_folder 路径（资源找不到）
- ❌ test() 无 self.run() 调用的空测试（被判定 stub_test_method）

## 11. 可复用范围

| 资源类型 | 示例 | 适配差异 |
|---------|------|---------|
| 语音包 | festival voices, espeak-ng-data | 路径 + EST/wav 格式签名 |
| 音频包 | sound-theme | 路径 + WAV/OGG header |
| 字体包 | fonts | 路径 + TTF/OTF header |
| 图标包 | icon-themes | 路径 + SVG/PNG header |
| 固件 | firmware blobs | 路径 + SHA256 + 版本号 |
| 数据包 | dictionaries | 路径 + SHA256 + 编码检查 |

核心方法不变：空 build() + 文件复制 + 消费者资源断言 + 分开统计上游/新增测试。
