# E220: OHOS native interpreter/toolchain composite adaptation

## 基本信息
- **严重度**: 3
- **类别**: filesystem|permissions|toolchain|runtime-feature-detection
- **触发工具**: Configure|make|install|conan
- **阶段**: configuration|build|installation|runtime

## 错误特征
```
ln.*Operation not permitted|touch:.*Permission denied|not writable by you|Can't create.*lib/auto|SIGSYS caught|Can't set \$0 with prctl
```

**关键词**: perl, Configure, metaconfig, hardlink, symlink, LNS, touch, miniperl, ExtUtils::Install, installperl, POSIX::access, -w, write probe, create unlink, IPC/SysV, prctl, PR_SET_NAME, tool_requires

## 根因分析
OHOS true-device storage and runtime can diverge from POSIX/Linux assumptions in several independent ways: hardlink/symlink creation may be denied, metadata-only touch on generated executables may fail, -w or POSIX::access(W_OK) may not match actual create/unlink ability, and Configure may detect headers/symbols for runtime features that later fail with SIGSYS/EINVAL.

**影响范围**: Native interpreter or toolchain packages whose upstream build systems use link-as-copy shortcuts, timestamp refresh rules, Perl/ExtUtils-style install checks, or configure-time feature probes that are not enough to prove true-device runtime availability.

## 修复方案
**推荐方案**: composite-ohos-toolchain-adaptation

Treat repeated build failures as a connected platform pattern instead of isolated patches: replace upstream link shortcuts with a copy-link wrapper that preserves relative-source semantics; remove timestamp-only touch steps on generated executables; replace unreliable permission predicates with actual create/unlink probes; and disable runtime features when true-device execution proves configure probes are false positives.

**命令**: Set TMPDIR/TMPPREFIX to a build-local writable path; pass Configure through an explicit shell; set lns/LNS to an OHOS copy-link wrapper; patch writeability checks to probe create/unlink; disable misdetected runtime features such as IPC/SysV or HAS_PRCTL_SET_NAME when true-device tests prove SIGSYS/EINVAL failures.
