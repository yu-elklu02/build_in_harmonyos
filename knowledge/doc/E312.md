# E312 - groonga 上游 grntest Ruby 测试框架依赖链在 OHOS 的完整解决方案

## 使用说明

groonga（及使用 grntest Ruby 框架的衍生库）上游 4227 个 .test 用例在 OHOS 上从"无法运行"到"全部实跑"的完整依赖链解决方案。依赖链分五层，逐层解决后可实测运行全部用例。

## 适用范围

- 上游测试基于独立 Ruby 工具 grntest（需 git clone + bundle install 获得）。
- 测试需启动完整 groonga 服务进程，通过 GQTP 协议/HTTP 逐条执行 4227 个 .test 用例并与 .expected 比对。
- OHOS 环境缺 Ruby C 扩展编译头、缺 /usr/bin/install、ELF 需签名。

## 输入定义

- 上游测试库存：`test/command/suite` 目录 4227 个 .test 用例（+4222 个 .expected）。
- 依赖 gem：msgpack/json（C 扩展）、grntest、groonga-command、groonga-command-parser、gqtp、groonga-client、groonga-log、groonga-query-log、groonga-synonym、charty、matplotlib、pycall、diff-lcs、rexml 等。

## 输出定义

- 本地实测 4227 用例全部运行：3373 PASS（79.8%）、140 FAIL、714 OMITTED、0 LEAKED。
- 140 FAIL 主因：simdjson/blosc/mecab/llama/bfloat16 等可选特性未启用（require-feature）+ 个别边界差异。
- 714 OMITTED 主因：require-feature（可选特性）与 groonga-httpd/nginx 组件未提供。

## 实现（五层依赖链）

1. **C23 stdckdint.h 补头**：OHOS musl libc 缺 stdckdint.h，msgpack/json/pycall 的 C 扩展 extconf 编译失败——创建 `usr/local/include/stdckdint.h`（基于 `__builtin_add/sub/mul_overflow` 实现 ckd_add/ckd_sub/ckd_mul），gem 编译传 `--with-cflags="-I/usr/local/include"`。
2. **/usr/bin/install 替代**：gem make install 硬编码 `/usr/bin/install`（OHOS 无）——`make DESTDIR= sitearchdir=./.gem.install sitelibdir=./.gem.install install INSTALL="/system/bin/install -c"`，再复制 .so 到 gem lib + `gem.build_complete` + specifications 注册。
3. **grntest 全套 gem 安装**：msgpack/json/pycall（C 扩展补头编译）+ grntest 及 6 个附加 gem（--local 安装）。
4. **测试接口选择**：grntest 默认 stdio 接口与 groonga 多行 JSON load 命令不兼容（`invalid command name: [`）——改用 `--interface=http`（groonga 以 `--protocol http` 启动，JSON 经 HTTP 传递）。
5. **ELF 签名**：groonga 二进制、libgroonga.so、groonga-suggest-create-dataset、plugins/*.so 全部 `binary-sign-tool sign -selfSign 1`（llvm-objcopy 移除 .codesign 后签名），否则运行/加载报 Permission denied。

## 本库落地

groonga 16.0.8（PR #3731）：五层依赖链全部解决 + 启用 MessagePack（重新构建 message_pack:true）+ 插件路径修复 + back trace 归一化 + TZ=Asia/Tokyo + stdio 用例 HTTP 执行后，`grntest --interface=http --groonga=<signed groonga> --base-directory=... test/command/suite` 实测 4227 用例全部运行，3373 PASS（79.8%），140 FAIL（simdjson/blosc/mecab/llama/bfloat16 等可选特性未启用），714 OMITTED（require-feature/groonga-httpd）。
