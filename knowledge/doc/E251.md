## 使用说明

当适配 OHOS 平台的 NLP 词典/分词数据包时使用本条目。本条目以 mecab-ko-dic 2.1.1-20180720（Korean MeCab Dictionary Data）为例。

## 适用范围

- 韩语/其他语言 MeCab 词典数据包（mecab-ko-dic、mecab-ipadic 等）
- 任何以 CSV/DEF 为词典源文件、以 mecab-dict-index 为索引生成工具的 NLP 数据包

## 数据完整性校验

### CSV/DEF 文件统计

```
CSV 文件: 40
DEF 文件: 9
dicrc: 1
CSV 总行数: 816,283
```

### UTF-8 编码校验

所有 CSV/DEF/dicrc 文件必须通过 UTF-8 iconv 校验（失败数=0）。

### 固定样本文本分词比对

```
输入: 화학 이외의 것
预期输出:
  화학  NNG,*,T,화학,*,*,*,*
  이외  NNG,*,F,이외,*,*,*,*
  의    JKG,*,F,의,*,*,*,*
  것    NNB,*,T,것,*,*,*,*
  EOS
```
