# E283 - Conan library 包的 shared 选项契约

## 使用说明

在 Conan 2 配方声明 `package_type = "library"` 时，用本条目建立稳定的静态/共享包模型。该模式适用于 CMake、Autotools、Meson 和自定义构建系统。

## 适用范围

- 配方产出可链接库。
- 消费者需要通过包选项选择静态或共享链接。
- CI 报 `Package type is 'library', but no 'shared' option declared`，或相同源码产生不稳定包 ID。

## 输入定义

- Conan 配方及目标库名。
- 构建系统控制静态/共享产物的变量或参数。
- 项目默认链接策略。

## 输出定义

- 标准 `shared` 选项和确定的默认值。
- `shared=False` 与 `shared=True` 具有不同且可复现的包 ID。
- 构建系统收到与 Conan 选项一致的链接类型。

## 实现

```python
class LibraryConan(ConanFile):
    package_type = "library"
    options = {"shared": [True, False]}
    default_options = {"shared": False}
```

CMake 示例：

```python
def generate(self):
    tc = CMakeToolchain(self)
    tc.variables["BUILD_SHARED_LIBS"] = bool(self.options.shared)
    tc.generate()
```

Autotools 配方不能只声明 `shared` 而假定构建系统一定收到对应参数。应检查生成的 `configure_args`，并在缺失时显式补齐且避免重复：

~~~python
def generate(self):
    tc = AutotoolsToolchain(self)
    link_args = (
        ["--enable-shared", "--disable-static"]
        if self.options.shared
        else ["--disable-shared", "--enable-static"]
    )
    for arg in link_args:
        if arg not in tc.configure_args:
            tc.configure_args.append(arg)
    tc.generate()
~~~

## 示例

```bash
conan create recipe -o 'pkg/*:shared=False'
conan create recipe -o 'pkg/*:shared=True'
```

静态包应只包含 `.a`，共享包应只包含 `.so` 及其必要链接；两种配置都必须运行真实消费者测试。

## 禁止做法

- `package_type = "library"` 却不声明 `shared`。
- 声明 `shared` 但不传给构建系统。
- 无论选项值如何都构建相同产物，再依赖文件复制偶然过滤。
