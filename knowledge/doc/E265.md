# E265 — OHOS 上运行 Linux 文件系统镜像类上游测试的兼容性处理

## 错误特征

OHOS 环境下运行 Linux 文件系统镜像类上游测试（如 fatsort 的 `make tests`）时，遇到以下典型失败：

- `/tmp` 路径上 `mkdir` 失败 → `Read-only file system`
- `SHELL=/bin/bash` 不存在
- `grep: -oP` 不支持（Perl 正则不可用）
- `locale: Cannot set LC_ALL to en_US.UTF-8`
- `valgrind: not found` — 4 个 `tc_pos_valgrind_*` 测试无法执行
- `bbe: not found`、`dosfstools` 缺失

## 触发条件

- 构建系统: Makefile（`testconfig.mk` 驱动）
- 阶段: testing（`make tests`）
- 典型库: fatsort、其他使用文件系统镜像测试的 Linux 工具

## 根因分析

OHOS 的 `/tmp` 是 erofs 只读文件系统，而上游测试硬编码 `/tmp` 路径用于创建临时文件、目录和挂载点。此外 OHOS 环境缺少完整 Linux 用户态工具链：`/bin/bash` 不存在、`grep` 编译时 `--disable-perl-regexp`、`locale` 仅支持 C/POSIX、`valgrind` 不可用。

## 解决方案

### 推荐方案

1. **可写目录**：通过 `TMPDIR`/`FS_IMG` 环境变量覆盖到可写目录（如 `/storage/Users/currentUser/tmp`）
2. **Shell 路径**：覆盖 `SHELL=/data/service/hnp/bin/bash`
3. **grep -oP**：替换为 `sed -nE`（patch 0004）
4. **Locale**：`LC_ALL=C` 替代 `en_US.UTF-8`，按 C locale 重新生成 expected 输出（patch 0005 + 0006）
5. **Valgrind**：专用测试标记为 skip，使用 clang ASan/UBSan 替代内存检查验证

### ASan/UBSan 替代验证步骤（覆盖 4 个 FAT 文件系统镜像）

```bash
# 1. 确认 sanitizer runtime 存在
ls /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib/clang/15.0.4/libclang_rt.asan.*
ls /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib/clang/15.0.4/libclang_rt.ubsan_standalone.*

# 2. 最小 ASan/UBSan 程序验证
echo 'int main() { int a[10]; a[20] = 42; return 0; }' | \
  /data/service/hnp/bin/clang -x c - -fsanitize=address,undefined -o /storage/Users/currentUser/tmp/test_asan
/storage/Users/currentUser/tmp/test_asan 2>&1 | grep -q 'heap-buffer-overflow' && echo 'ASan OK'

# 3. 构建 fatsort with ASan/UBSan
make -C src CC=/data/service/hnp/bin/clang LD=/data/service/hnp/bin/clang \
  CFLAGS="-fPIC -O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer -D__LINUX__" \
  LDFLAGS="-fsanitize=address,undefined"

# 4. 确认二进制包含 ASan/UBSan 符号
readelf -s src/fatsort | grep -i asan

# 5. 在 4 个 FAT 文件系统镜像上分别执行 ASan/UBSan 验证
# 场景 1: exFAT
xz -d -f --stdout tests/images/exfat_good_dirs_and_files.img.xz > /storage/Users/currentUser/tmp/fs.img
ASAN_OPTIONS="halt_on_error=1:abort_on_error=1:detect_leaks=0" \
UBSAN_OPTIONS="halt_on_error=1:print_stacktrace=1" \
src/fatsort /storage/Users/currentUser/tmp/fs.img 2>&1 | grep -v "WARNING: The C locale"

# 场景 2: FAT12
xz -d -f --stdout tests/images/fat12_good_dirs_and_files.img.xz > /storage/Users/currentUser/tmp/fs.img
ASAN_OPTIONS="halt_on_error=1:abort_on_error=1:detect_leaks=0" \
UBSAN_OPTIONS="halt_on_error=1:print_stacktrace=1" \
src/fatsort /storage/Users/currentUser/tmp/fs.img 2>&1 | grep -v "WARNING: The C locale"

# 场景 3: FAT16
xz -d -f --stdout tests/images/fat16_good_dirs_and_files.img.xz > /storage/Users/currentUser/tmp/fs.img
ASAN_OPTIONS="halt_on_error=1:abort_on_error=1:detect_leaks=0" \
UBSAN_OPTIONS="halt_on_error=1:print_stacktrace=1" \
src/fatsort /storage/Users/currentUser/tmp/fs.img 2>&1 | grep -v "WARNING: The C locale"

# 场景 4: FAT32
xz -d -f --stdout tests/images/fat32_good_dirs_and_files.img.xz > /storage/Users/currentUser/tmp/fs.img
ASAN_OPTIONS="halt_on_error=1:abort_on_error=1:detect_leaks=0" \
UBSAN_OPTIONS="halt_on_error=1:print_stacktrace=1" \
src/fatsort /storage/Users/currentUser/tmp/fs.img 2>&1 | grep -v "WARNING: The C locale"
```

注意：如果 /tmp 是只读文件系统，使用可写目录替代（如 /storage/Users/currentUser/tmp）。
注意：FAT12 文件系统在 aarch64 上存在未对齐访问问题，需在 getFATEntry() 中使用 memcpy 替代直接指针解引用。
注意：stdout 排序顺序差异因 OHOS 使用 C locale 而非 en_US.UTF-8，不影响 ASan/UBSan 验证核心结论。

### 完整上游测试命令

```bash
make tests SHELL=/data/service/hnp/bin/bash \
  TMPDIR=/storage/Users/currentUser/tmp \
  FS_IMG=/storage/Users/currentUser/tmp/fs.img \
  FATSORT=../src/fatsort LC_ALL=C
```

### 禁止做法

- ❌ 禁止将 `tc_pos_valgrind_*` 标记为通过（OHOS 无 valgrind）
- ❌ 禁止写 125/125 或 100%（实际通过率 121/125，96.8%）
- ❌ 禁止将 ASan/UBSan 替代验证合并到上游测试通过率中
- ❌ 禁止写"上游无测试用例"（上游有 125 个测试）
- ❌ 禁止 ASan/UBSan 替代验证仅做 -v/-h smoke（必须覆盖 4 个 FAT 文件系统镜像的真实数据流，分别统计为 4/4）
- ❌ 禁止写 valgrind 4/4 通过（valgrind 本体不可用，替代验证是 ASan/UBSan 的 4/4）

## 验证

```bash
# 确认上游测试结果（不含 valgrind）
make tests ... 2>&1 | grep -E 'PASS|FAIL|skip|summary'
# 结果应为：121/125 通过或适配后通过，4/125 valgrind 跳过

# 确认 ASan/UBSan 替代验证（4 个 FAT 文件系统镜像）
export ASAN_OPTIONS="halt_on_error=1:abort_on_error=1:detect_leaks=0"
export UBSAN_OPTIONS="halt_on_error=1:print_stacktrace=1"
# 场景 1: exFAT → 无 ASan/UBSan 错误
# 场景 2: FAT12 → 无 ASan/UBSan 错误（需先修复未对齐访问）
# 场景 3: FAT16 → 无 ASan/UBSan 错误
# 场景 4: FAT32 → 无 ASan/UBSan 错误
# 替代内存检查验证通过率：4/4（100%）
```
