# E216: Boost.Build 在 OHOS 注入错误 Linux target triple

## 状态

路径 B 正式知识。已在 Boost.Test 1.84.0 的 4 个目标上完成 b2 日志、直编、链接和运行对照验证。

## 问题

Boost.Build 调用 OHOS clang 时会错误附加 `--target=arm64-pc-linux`。该 Linux triple 使 SDK 默认的 OHOS C++ 头文件发现失效，编译报 `cstddef file not found`；在部分缓存状态下，b2 还会错误 no-op 而不产生构建动作。删除这一项后，保持其余 b2 编译参数不变的直编、链接和运行均稳定通过。

## 诊断与修复

```sh
b2 -j1 -d+2 <target> 2>&1 | tee <target>-b2.log
# 从 b2 日志提取完整 clang++ 命令，仅删除 --target=arm64-pc-linux
<exact-clang-command-without-invalid-target> 2>&1 | tee <target>-direct.log
```

验证范围：`algorithm-test`、`message-in-datatestcase-test`、`assertion-construction-test` 和 `doc-exception_check`。两轮真机直编无 error；已完成的 61 个编译动作均成功，目标二进制可完成链接和运行。

## 适配边界

仅移除 `--target=arm64-pc-linux`，不能删除其他 target/sysroot/ABI 选项，也不能将该知识泛化到非 OHOS clang 工具链。E074 处理 GNU make jobserver/FIFO 问题，与本条目的 Boost.Build target triple 问题不同。
