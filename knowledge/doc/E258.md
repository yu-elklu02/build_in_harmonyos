# E258: meson.options 与 meson_options.txt 双文件（符号链接物化）导致 meson 拒绝配置

> **Contributor**: yanjiaxin | **Status**: Verified | **Updated**: 2026-08-07
> **Severity**: 2 | **Category**: meson / file-layout / symlink

## 错误特征

```text
meson.options and meson_options.txt both exist, but are not the same file
```

## 触发条件

- 构建系统: meson
- 阶段: configuration

## 根因分析

上游源码同时携带 meson.options 与 meson_options.txt（后者是前者的符号链接）。在 HMDFS
等文件系统上复制源码时符号链接被物化为独立普通文件，meson >= 1.5 检测到两份内容相同但
非同一 inode 的文件时报错。

## 解决方案

### 推荐方案

删除 meson_options.txt（或恢复其为 meson.options 的符号链接），使两者为同一文件：

```bash
rm -f meson_options.txt
```

meson 0.63+ 支持 meson.options 命名。conan get() 的 tarfile 提取保留符号链接不受影响。

## 验证

```bash
ls -la meson.options meson_options.txt && meson setup build
```
