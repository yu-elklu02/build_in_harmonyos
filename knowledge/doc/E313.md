# E313 - Ruby C 扩展 gem 在 OHOS musl libc 缺 C23 stdckdint.h 与 /usr/bin/install 的解决方案

## 使用说明

含 C 扩展的 Ruby gem（msgpack/json/pycall 等）在 OHOS 上 gem install 时两类失败：① extconf 编译缺 C23 stdckdint.h；② make install 缺 /usr/bin/install。本条目提供完整解决流程。

## 适用范围

- 任意 Ruby C 扩展 gem，其代码或依赖链引用 C23 头文件 stdckdint.h。
- OHOS musl libc 环境（缺少 stdckdint.h，仅有 /system/bin/install）。
- 间接影响：依赖这些 gem 的上游测试框架（grntest → msgpack/json/pycall）。

## 输入定义

- 报错①：`ruby/internal/stdckdint.h:48: error: 'stdckdint.h' file not found`。
- 报错②：`make: /usr/bin/install: No such file or directory`（Error 127）。
- 触发：`gem install msgpack/json/pycall`（C 扩展 extconf + make install）。
- 环境：OHOS musl libc，ruby 3.4.5 / gem 3.6.9 / bundle 2.6.9。

## 输出定义

- msgpack/json/pycall 编译 + 安装成功，`require` 可用。
- grntest 依赖链完整，上游测试可实跑。

## 实现

1. **补 stdckdint.h**：创建 C23 兼容头到用户可写 include 目录（如 `/storage/Users/currentUser/usr/local/include/stdckdint.h`），内容：
   ```c
   #define __STDC_VERSION_STDCKDINT_H__ 202311L
   #define ckd_add(result, a, b) __builtin_add_overflow((a), (b), (result))
   #define ckd_sub(result, a, b) __builtin_sub_overflow((a), (b), (result))
   #define ckd_mul(result, a, b) __builtin_mul_overflow((a), (b), (result))
   ```
2. **gem 编译补头**：`gem install msgpack -- --with-cflags="-I/storage/Users/currentUser/usr/local/include"`（CFLAGS 环境变量对 mkmf 不生效，必须用 --with-cflags）。
3. **make install 覆盖**：`make DESTDIR= sitearchdir=./.gem.install sitelibdir=./.gem.install install INSTALL="/system/bin/install -c"`。
4. **手动完成注册**：复制 .so 到 gem lib 目录 + `touch extensions/.../gem.build_complete` + 手写 Ruby 代码格式的 `specifications/<name>-<ver>.gemspec`（`Gem::Specification.new do |s| ... end`，YAML 格式 `--- !ruby/object` 不被 rubygems 接受）。
5. **多扩展 gem**：json 需分别编译 generator 和 parser 两个 C 扩展（ext/json/ext/generator、ext/json/ext/parser），均按上述流程。

## 本库落地

groonga 16.0.8（PR #3731）：msgpack-1.8.4/json-2.21.2/pycall-1.5.2 均按上述流程编译安装成功，`require 'msgpack'`/`require 'json'`（2.21.2）可用，grntest 依赖链完整。
