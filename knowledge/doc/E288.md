# E288 - CMake 双库目标收敛为单一可选产物

## 使用说明

当上游 CMake 同时声明 `foo-static` 和 `foo-shared`，而 Conan 需要用一个 `shared` 选项控制产物时使用。本条目将目标定义收敛为标准 CMake 单目标模型。

## 适用范围

- 上游显式使用 `add_library(... STATIC ...)` 与 `add_library(... SHARED ...)`。
- 设置 `BUILD_SHARED_LIBS` 后仍同时安装 `.a` 和 `.so`。
- 两个目标使用相同源码并只在输出类型上不同。

## 输入定义

- 上游 CMake 目标、源码列表、输出名称、安装规则。
- Conan `shared` 布尔选项。
- 下游期望的 CMake target 名和库文件名。

## 输出定义

- 一个未显式指定 `STATIC/SHARED` 的库目标。
- `BUILD_SHARED_LIBS` 唯一决定链接类型。
- 包中只出现所选类型，头文件和 target 名保持稳定。

## 实现

```cmake
add_library(replaygain gain_analysis.c)
set_target_properties(replaygain PROPERTIES OUTPUT_NAME replaygain)
install(TARGETS replaygain
        ARCHIVE DESTINATION lib
        LIBRARY DESTINATION lib)
```

```python
tc.variables["BUILD_SHARED_LIBS"] = "ON" if self.options.shared else "OFF"
```

## 示例验证

```bash
(
  set -eu
  REF="pkg/version"
  PKG="${REF%%/*}"
  VER="${REF#*/}"
  WORK_ROOT="$(mktemp -d)"
  trap 'rm -rf "$WORK_ROOT"' EXIT
  STATIC_DEPLOY="$WORK_ROOT/static"
  SHARED_DEPLOY="$WORK_ROOT/shared"

  conan create recipe -o "$PKG/*:shared=False"
  conan create recipe -o "$PKG/*:shared=True"
  conan install --requires="$REF" -o "$PKG/*:shared=False" \
    --deployer=full_deploy --deployer-folder="$STATIC_DEPLOY"
  conan install --requires="$REF" -o "$PKG/*:shared=True" \
    --deployer=full_deploy --deployer-folder="$SHARED_DEPLOY"

  STATIC_ROOT="$STATIC_DEPLOY/full_deploy/host/$PKG/$VER"
  SHARED_ROOT="$SHARED_DEPLOY/full_deploy/host/$PKG/$VER"
  STATIC_LIB="$(find "$STATIC_ROOT" -type d -name lib -print -quit)"
  SHARED_LIB="$(find "$SHARED_ROOT" -type d -name lib -print -quit)"

  test -n "$STATIC_LIB"
  test -n "$SHARED_LIB"
  test -n "$(find "$STATIC_LIB" -type f -name '*.a' -print -quit)"
  test -z "$(find "$STATIC_LIB" \( -type f -o -type l \) \
    -name '*.so*' -print -quit)"
  test -n "$(find "$SHARED_LIB" \( -type f -o -type l \) \
    -name '*.so*' -print -quit)"
  test -z "$(find "$SHARED_LIB" -type f -name '*.a' -print -quit)"
)
```

还需用 CMakeDeps 生成的目标链接消费者程序，避免只检查文件扩展名。

## 禁止做法

- 只设置 `BUILD_SHARED_LIBS`，但保留显式 `STATIC/SHARED` 双目标。
- 同时打包两类库却只声明一个 Conan 包 ID。
- 改变公开库名或 CMake target 名而不提供兼容映射。

## 验证证据

PR #2105 与 #2107 分别对 ReplayGain 和 CUE 文件库验证了该模型，证明它不依赖单个库的 API。
