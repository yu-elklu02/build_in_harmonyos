# E250: OHOS 原生环境不含 Go 工具链，go build 失败

> **Contributor**: goblinrs | **Status**: Verified | **Updated**: 2026-07-17
> **Severity**: 3 (blocking) | **Category**: build_tool_missing / go

## 错误特征

```text
/bin/sh: go: inaccessible or not found
make: *** [build] Error 127
```

## 触发条件

- 阶段：compilation
- 平台：OpenHarmony PC aarch64
- 典型项目：所有 Go 语言项目（flow-cli, croc, gh-dash 等）

## 根因分析

OpenHarmony PC 原生环境未预装 Go 工具链，PATH 中不包含 go 二进制，导致所有 Go 语言项目的编译步骤失败。

## 解决方案

### 推荐方案：在 conanfile.py 中自动下载 Go SDK

在 `build()` 中自动下载 Go SDK 二进制发布版，解压后设置 GOROOT 和 PATH，然后执行 go build：

```python
from conan.tools.files import get
get(self, url=f"https://go.dev/dl/go{go_version}.linux-arm64.tar.gz",
    sha256=go_sha256, destination=go_dest, strip_root=False)
os.environ["GOROOT"] = ...
os.environ["PATH"] = ...
```

### 回退方案

从 cmd-pkgs 仓库安装预编译的 Go 工具链：

```bash
curl -fsSL https://gitcode.com/OpenHarmonyPCDeveloper/cmd-pkgs/releases/download/pkgs/install.sh | sh -s -- go <version>
```

## 禁止做法

- 不要仅用 `shutil.which("go") or "go"` 尝试，Worker 上无 Go 时命令仍会失败。
