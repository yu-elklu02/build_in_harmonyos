# E291 — 既有正式条目的 graph validate 问题导致 finish/W4 阻塞（repository_baseline_blocked）


## 触发工具 / 阶段 / 错误特征

- 工具：`ohc-run.py finish`（内部 W4 知识图谱完整性检查调用 `graph validate`）
- 阶段：finish Step 5/8（W4）→ STEP_FAILED: Step6
- 错误特征：
  - `finish` 顶层退出码 1，`STEP_FAILED: Step6`
  - `W4: 知识图谱完整性检查发现 1 类问题`
  - `graph validate`：`E213: non-standard fields: ['pattern','software','solution','symptom']`、`E214: non-standard fields: [...]`、`E213: unknown principle R6/R12` → `4 errors, 12 warnings`

## 真实事实（openal-soft 1.25.2 实测）

| 项 | 结果 |
|---|---|
| conan create | rc=0（Package 'e18bda…' created，test_package 全 PASS） |
| conan-verify | rc=0（G0/G2/G3/G4 全 PASS，可标记 published） |
| release/debug tar.gz | 已由 PackageBuilder 真实生成（2 个，5.78MB + 1.50MB，含 .packaged 标记） |
| W3 本地 CI | 通过；`.ci-result.json` 由框架 W3 生成（本轮时间戳） |
| finish 顶层退出码 | **1**（STEP_FAILED: Step6） |
| W4/Step6 失败原因 | 既有正式条目 E213/E214 等 graph validate 问题（与 openal 源码、配方、测试无关） |
| 内部知识整理 EXIT_CODE | 0（`EXIT_REASON: finish_success`）——**不能替代 finish 顶层通过** |

## 根因与影响范围

- 根因：仓库 `knowledge/graph/` 既有正式条目（E213/E214 等）存在 non-standard fields / unknown principle 问题；W4 依赖全库 `graph validate` 通过，基线问题使任何库的 finish 顶层无法通过。
- 影响范围：所有需要执行 finish 的库（W4/Step6 是全库级检查，非当前库私有）。
- 与当前库（openal）源码、配方、测试**无关**。

## 验证入口

```bash
python3 scripts/ohc-run.py graph validate 2>&1 | grep -E 'E213|E214|errors|warnings'
# → ❌ 4 errors, 12 warnings（既有：E213/E214 non-standard fields、E213 unknown principle R6/R12）
python3 scripts/ohc-run.py finish openal-soft 1.25.2 built > finish.log 2>&1; echo rc=$?
# → rc=1，STEP_FAILED: Step6，W4 1 类问题
```

## 推荐处理

- 记录状态 `repository_baseline_blocked`，保存：graph validate 命令与退出码、首个错误（E213/E214）、finish 日志、恢复条件。
- **禁止**把 W3 或 `.ci-result.json` 单独写成 finish 通过。
- **禁止**把 E213/E214 修复混入当前库 PR（属仓库基线条目，应单独 PR）。
- 重复/关联说明：与既有条目部分重复属预期，本条目聚焦"工具链全通过但 finish 顶层被仓库基线阻塞"的组合场景，保留待维护者审核。

## 恢复条件

仓库维护者修复既有 E213/E214 等基线条目后，重新执行 openal 的 conan create、conan-verify、finish、W3；届时 finish 顶层退出码应变为 0。

## 关联条目

- E213 / E214：既有正式条目（non-standard fields / unknown principle），本条目 caused 的根源（未修改它们）。
- E216：openal-soft 1.25.2 探针取证 条目（同库）。
