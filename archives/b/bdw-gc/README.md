# bdw-gc

Boehm-Demers-Weiser conservative garbage collector for C and C++.

## Available Versions
- 8.2.6 (built)

## Description
bdw-gc is a garbage collector for C and C++ that automatically manages memory.
It provides GC_MALLOC/GC_FREE as drop-in replacements for malloc/free, with
automatic collection of unreachable memory.
