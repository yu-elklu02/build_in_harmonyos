# GNU Barcode

GNU Barcode is a command-line generator for conventional product-tagging
standards such as EAN, UPC, ISBN, Code 128, and Code 39.

## HarmonyOS adaptation

- Version `0.99` is packaged as an application for OHOS `armv8`.
- It uses Autotools with a portable GNU build/host triplet for the legacy
  configure scripts.
- The consumer test generates a Code 128 SVG and validates the output.
