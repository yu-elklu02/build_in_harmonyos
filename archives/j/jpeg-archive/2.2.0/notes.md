# jpeg-archive 2.2.0

The upstream tag `v2.2.0` uses a Makefile, not CMake. The recipe builds the
three ELF utilities against the published `mozjpeg/4.1.1` package and installs
the upstream `jpeg-archive` shell wrapper alongside them.
