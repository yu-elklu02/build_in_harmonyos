# screenfetch

screenFetch — "The Bash Screenshot Information Tool". A CLI Bash script that
gathers system/theme/desktop-environment information and prints it alongside
an ASCII distribution logo, intended for use in screenshots.

- Homepage: https://github.com/KittyKatt/screenFetch
- Pure Bash script tool (no C compilation, no build system)
- Runtime needs Bash 4.0+ and common coreutils
- Installs the `screenfetch` command and the `screenfetch.1` man page
