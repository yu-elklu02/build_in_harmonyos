## Adaptation

The SISC Lite release archive contains a shell launcher, `sisc.jar`,
`sisc.shp`, and documentation files. There is no configure script, Makefile,
or native compilation step. The Conan recipe installs these files under
`libexec/sisc-scheme` and creates `bin/sisc`, a small wrapper that sets
`SISC_HOME` and invokes:

```sh
java -classpath "$SISC_HOME/sisc.jar" -Dsisc.home="$SISC_HOME" \
  sisc.REPL -h "$SISC_HOME/sisc.shp" "$@"
```

Runtime dependency: a JVM must be available as `java`. On OHOS this should be
provided by bishengjdk from cmd-pkgs.

## OHOS Notes

The installed `bin/sisc` wrapper is generated by the recipe. On the current
OHOS worker, direct exec with `#!/usr/bin/env bash` or `#!/bin/sh` returns
permission errors, and `/data/service/hnp/bin/bash` is absent. For OHOS
packages the recipe writes the absolute bash path found during packaging
(`shutil.which("bash")`), which was
`/storage/Users/currentUser/usr/local/bin/bash` in the verified run.
