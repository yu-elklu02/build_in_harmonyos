# sipsak

SIP stress and diagnostics utility - a command line tool for testing and troubleshooting SIP (Session Initiation Protocol) implementations.

## Description

sipsak is a SIP Swiss army knife that can be used for:
- SIP testing and verification
- SIP traceroute functionality
- SIP flooding and stress testing
- SIP message manipulation

## Version

- **0.9.7.1**: Current stable version (Conan package revision of upstream 0.9.7)

## Dependencies

None required. Optional dependencies:
- OpenSSL or GnuTLS for TLS support
- c-ares for DNS SRV lookup
