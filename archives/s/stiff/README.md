# STIFF

STIFF converts scientific FITS images to standard TIFF images.

## HarmonyOS PC adaptation

The recipe builds the command-line converter against the repository's static
libtiff, libjpeg, and zlib packages. It disables optional worker threads for a
portable baseline and validates a real FITS-to-TIFF conversion.
