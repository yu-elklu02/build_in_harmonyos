## 编译步骤

scdoc 使用简单 Makefile，无需 configure 步骤：

```bash
# 下载并解压
tar xzf scdoc-1.11.0.tar.gz
cd scdoc-1.11.0

# 应用补丁
patch -p1 < 0001-Makefile.patch
patch -p1 < 0002-include-str.h.patch
patch -p1 < 0003-src-string.c.patch

# 编译
make -j1

# 安装
make install PREFIX=/usr/local
```

## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| 1 | install 命令失败 | toybox install 不支持 `-m755` 紧凑格式 | 补丁修改为 `-m 755`（空格分隔） |
| 2 | 编译警告 | `str_create()` 空参数列表不标准 | 补丁修改为 `str_create(void)` |

## 源码修改

### 0001-Makefile.patch
修复 install 命令参数格式：
- `install -m755` → `install -m 755`
- 鸿蒙系统 toybox install 需要空格分隔

### 0002-include-str.h.patch
修复函数声明：
- `struct str *str_create()` → `struct str *str_create(void)`
- C 标准中空参数列表与 `(void)` 语义不同

### 0003-src-string.c.patch
修复函数定义：
- 同上，保持声明与定义一致
