# scala

Scala is a strong statically typed programming language which combines object-oriented and functional programming in one concise, high-level language.

## Versions

| Version | Status | Notes |
|---------|--------|-------|
| 2.12.21 | built  | JVM precompiled distribution |

## Description

Scala 2.12.21 is a JVM precompiled distribution containing:
- `bin/` — Shell script tools: fsc, scala, scalac, scaladoc, scalap
- `lib/` — JAR files: scala-library.jar, scala-compiler.jar, scala-reflect.jar, etc.
- `doc/` — Documentation
- `man/` — Man pages

## Dependencies

- **bishengjdk 17.0.13+** — JVM runtime (installed via cmd-pkgs, not a Conan package)
