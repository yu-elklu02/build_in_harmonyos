# GNU shtool

GNU shtool 是 GNU Portable Shell Tool，将多个稳定、可移植的 shell 辅助工具整合为一个命令行程序。

## 功能概述
- `shtool echo`：可移植增强 echo
- `shtool install`：可移植文件安装
- `shtool mkdir`：可移植目录创建
- `shtool version`：版本信息生成
- `shtoolize`：生成定制化 shtool 脚本
