# nspr

Netscape Portable Runtime (NSPR) — Mozilla 开发的跨平台可移植运行时库，为上层应用提供平台无关的 API 接口。

## 主要功能

- **线程管理**：跨平台的线程创建、同步和管理功能
- **IO 操作**：文件、网络、管道等 IO 操作的统一接口
- **内存管理**：内存分配、内存映射等功能
- **时间处理**：高精度计时器和时间格式化
- **进程管理**：进程创建、管道通信等
