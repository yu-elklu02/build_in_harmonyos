# nanorc

Improved Nano Syntax Highlighting Files for HarmonyOS PC.

## Description

This package provides enhanced syntax highlighting configuration files for the GNU Nano text editor. It includes syntax definitions for over 100 programming languages and file formats.

## Usage

After installation, add the following line to your `~/.nanorc` file:

```
include <package_path>/share/nanorc/*.nanorc
```

Or use the provided nanorc file:

```
cat <package_path>/share/nanorc/nanorc >> ~/.nanorc
```
