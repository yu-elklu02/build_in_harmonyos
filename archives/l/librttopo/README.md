# librttopo

RT Topology Library exposes the ISO 13249 / SQL/MM topology API derived from
PostGIS liblwgeom.

- Upstream: https://gitea.osgeo.org/rttopo/librttopo
- License: GPL-2.0-or-later
- Build system: Autotools
- Dependency: geos/3.13.1

## Versions

- 1.1.0 - official 1.1.0 source with the corrected OpenHarmony recipe,
  floating-point split fix, PIC support and complete GEOS propagation.
