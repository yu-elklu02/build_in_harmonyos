## Build

- Build system: Autotools
- Conan package type: library
- Options: `shared=True/False`, `fPIC`
- Dependencies: none
- Patches: `0001-config.guess.patch`, `0002-config.sub.patch`, `0003-configure-hmdfs-umask.patch`
- Status: built locally, not published

`AutotoolsToolchain` supplies the standard shared/static switches. The recipe only adds `--without-jpeg`, `--without-tiff`, and `--without-zlib` to keep the core ICC engine independent of optional image codecs. The portability patches update GNU platform recognition for the `linux-ohos` target and apply cleanly to the official 2.19 release archive. The `config.sub` patch preserves the upstream 2024 script and replaces a complete anchored block so Conan `patch-ng` cannot misplace the OHOS branch.

Formal CI build #7521 recognized `aarch64-unknown-linux-ohos`, then failed when `config.status` tried to write `confXXXXXX/subs1.awk` on HMDFS. Patch `0003-configure-hmdfs-umask.patch` changes only the two masks that create that temporary directory from `077` to `022`; it does not replace other security-sensitive umask settings globally. This follows knowledge entry E129 and leaves the existing `config.sub` fix unchanged.
