# libformfactor

libformfactor computes Fourier shape transforms for polyhedral particles.

## HarmonyOS PC adaptation

The recipe builds a static C++20 library, carries the required header-only
LibHeinz API, compiles the 18 upstream tests, and runs them on native targets.
