# HDF4

HDF4 is a library and multi-object scientific data format.

## HarmonyOS PC adaptation

The recipe builds the static HDF and MFHDF libraries with JPEG and zlib
support from existing Conan packages. Fortran, Java, tools, and examples are
disabled while the upstream C test suites remain enabled.
