# lastpass-cli

LastPass command line interface tool, for managing passwords in terminal.

## Version

| Version | Status | Date |
|---------|--------|------|
| 1.6.1 | built | 2026-08-10 |

## Dependencies

- openssl/1.1.1w
- libcurl/8.5.0
- libxml2/2.15.3

## Description

lastpass-cli is the official LastPass command line client, supporting login,
sync, add, edit, generate, duplicate, rm, mv, share, status, passwd operations.
Built with CMake, uses Conan for dependency management on OpenHarmony.
