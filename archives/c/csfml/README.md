# CSFML

CSFML 是 SFML 的官方 C 语言绑定。

## HarmonyOS 适配状态

2.6.0 版本独立依赖 `sfml/2.6.1`，当前支持 System 和 Network 模块。Window、Graphics、Audio 模块因 HarmonyOS PC 缺少对应的 SFML 窗口与音频后端而禁用。

## 可用模块

- `csfml-system`
- `csfml-network`

## 依赖

- `sfml/2.6.1` 的 System 和 Network 模块
