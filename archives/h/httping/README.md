# httping

httping is a command-line tool that measures HTTP server response times by sending HTTP requests.

## 适配版本

- 4.4.0：CMake 构建，默认关闭 SSL/TUI/FFTW3/gettext 可选功能，提供基础 HTTP ping 命令。
