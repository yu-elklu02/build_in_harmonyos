# hypre

hypre is a library of scalable linear solvers and multigrid methods.

## HarmonyOS PC adaptation

The recipe builds a sequential static library using hypre's internal BLAS and
LAPACK implementations. MPI, accelerator, OpenMP, and Fortran paths are
disabled for a dependency-free OHOS baseline.
