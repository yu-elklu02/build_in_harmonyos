# Halibut

多格式文档生成工具，支持 HTML / PDF / PostScript / man / info 等多输出格式。

## 软件信息

| 字段 | 值 |
|------|-----|
| 名称 | halibut |
| 版本 | 1.3 |
| 构建系统 | CMake |
| 许可证 | MIT |
| 上游主页 | https://www.chiark.greenend.org.uk/~sgtatham/halibut/ |

## 产出物

| 路径 | 说明 |
|------|------|
| `bin/halibut` | 文档生成命令行工具 |
| `share/man/man1/halibut.1` | man 手册页 |
| `share/info/halibut.info` | Info 格式文档 |
| `share/doc/halibut/` | HTML 格式用户手册 |

## 依赖

无外部运行时依赖（仅 C 标准库）
