# dnscrypt-proxy

A flexible DNS proxy, with support for modern encrypted DNS protocols such as DNSCrypt v2, DNS-over-HTTPS (DoH), Anonymized DNSCrypt, and Oblivious DoH (ODoH).

## Features

- DNSCrypt v2 protocol support
- DNS-over-HTTPS (DoH) support
- Anonymized DNSCrypt relay support
- Oblivious DoH (ODoH) support
- Query logging and blocking
- IP address encryption (IPCrypt)
- Captive portal detection
- DNS64 support
- Hot configuration reload
