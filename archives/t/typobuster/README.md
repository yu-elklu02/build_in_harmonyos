# typobuster

typobuster is a GTK3 text editor for common text transformations and typo cleanup.

## Adapted versions

| Version | Status | Conan reference |
| --- | --- | --- |
| 1.0.0 | built | `typobuster/1.0.0` |

The package installs the upstream Python module, language and icon assets, desktop metadata, and a `typobuster` launcher. Runtime requires Python 3, PyGObject, GTK3, and GtkSourceView4 on OpenHarmony.
