# wrk

Modern HTTP benchmarking tool capable of generating significant load
when run on a single multi-core CPU. Uses a LuaJIT-based scripting
interface for custom request generation and response processing.

- **Upstream**: https://github.com/wg/wrk
- **License**: Apache-2.0
- **Build system**: Makefile (with embedded LuaJIT-2.1 and OpenSSL-1.1.1i)
