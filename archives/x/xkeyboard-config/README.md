# xkeyboard-config

X Keyboard configuration data (XKB rules, symbols, keycodes, compat, types, geometry).

## Description
xkeyboard-config is the XKB keyboard configuration database used by X.Org.
It provides keyboard layout definitions, rules, and configuration data for
X Window System keyboard handling.
