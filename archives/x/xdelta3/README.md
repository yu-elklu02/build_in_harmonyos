# xdelta3

VCDIFF (RFC 3284) delta compression library and tool.

- **Homepage**: https://github.com/jmacd/xdelta
- **License**: Apache License 2.0
- **Build system**: CMake (>= 3.13)
- **Language**: C99 / C++11

## Products

| Product | Description |
|---------|-------------|
| `xdelta3` | Command-line tool for encoding/decoding VCDIFF deltas |
| `libxdelta3.a` | Static library exposing the `xd3_*` API |
| `xdelta3.h` | Public header |

## Dependencies

| Dependency | Version | Purpose |
|------------|---------|---------|
| xz | 5.6.2 | liblzma for LZMA secondary compression |
