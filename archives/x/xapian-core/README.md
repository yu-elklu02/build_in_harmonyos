# Xapian Core

## 简介

Xapian Core 是一个高性能的搜索引擎核心库，提供强大的全文检索功能和索引能力。

## 基本信息

- **软件名称**: xapian-core
- **显示名**: Xapian Core
- **描述**: 搜索引擎核心库
- **分类**: library
- **官网**: https://xapian.org/
- **许可证**: GPL-2.0
- **构建系统**: autotools
