# orocos-kdl

机器人运动学与动力学库：正/逆解、雅可比、动力学。

用几何原语（Frame / Rotation / Twist）描述机械臂，再在其上做正逆运动学
与动力学求解。底层向量与旋转基于 Eigen。

- 上游：https://github.com/orocos/orocos_kinematics_dynamics
- 许可证：LGPL-2.1-or-later
