# EB Library

EB Library is a C library and command-line tool suite for accessing EB, EBG, EBXA, and EPWING CD-ROM dictionaries.

## Versions

| Version | Status | Build system | Required dependencies |
| --- | --- | --- | --- |
| 4.4.3 | built | Autotools | zlib/1.3.1 |

The 4.4.3 recipe disables optional NLS, enables pthread and EBNET/IPv6 support, builds the upstream samples, and packages the static library plus EB utilities.
