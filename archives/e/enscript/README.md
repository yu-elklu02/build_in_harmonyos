# enscript

GNU enscript 将 ASCII 文本文件转换为 PostScript、HTML、RTF、ANSI 等格式，
可直接输出到文件或发送到打印机，并支持语法高亮、多栏排版、页眉页脚等特性。

- 上游主页：https://www.gnu.org/software/enscript/
- 许可证：GPL-3.0-or-later
- 类型：命令行工具（enscript / mkafmmap / states 等）
