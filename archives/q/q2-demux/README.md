# q2-demux

q2-demux is a QIIME 2 plugin for demultiplexing sequence reads. It maps sequence barcodes to samples.

## Key Information

- **Homepage**: https://qiime2.org
- **Source**: https://github.com/qiime2/q2-demux
- **License**: BSD-3-Clause
- **Language**: Python

## Description

This plugin provides methods for demultiplexing multiplexed sequence data, including:

- EMP (Earth Microbiome Project) protocol demultiplexing
- Error correction of barcode reads
- Subsampling and filtering of demultiplexed reads
- Summarization and quality visualization
