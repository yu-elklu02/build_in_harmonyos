# qtwebsockets

Qt WebSockets provides C++ client and server APIs for RFC 6455 WebSocket
communication as part of Qt 6.

## Package

- Upstream: https://doc.qt.io/qt-6/qtwebsockets-index.html
- Source: https://download.qt.io/official_releases/qt/6.11/6.11.1/submodules/
- Conan reference: `qtwebsockets/6.11.1`
- Build system: CMake
- Runtime dependency: `qtbase/6.11.1`
