# md5deep

递归计算与审计文件哈希的命令行工具家族（hashdeep/md5deep）。一份二进制按
`argv[0]` 分派为 6 个命令：`hashdeep`、`md5deep`、`sha1deep`、`sha256deep`、
`whirlpooldeep`、`tigerdeep`，分别计算 MD5 / SHA-1 / SHA-256 / Whirlpool /
Tiger 摘要，支持递归遍历目录与已知哈希清单审计。

- 上游仓库：https://github.com/jessek/hashdeep
- 许可证：主体公有领域（US Gov 作品），Tiger 代码为 GPL-2.0
- 类型：命令行工具（tool）
