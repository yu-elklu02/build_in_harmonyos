## OHOS fixes

- Map Autotools tool variables to OHOS LLVM tools: `llvm-ar`, `ld.lld`, `llvm-ranlib`, `llvm-nm`, `llvm-objdump`, and `llvm-strip`.
- Patch `configure` to create `config.status` temporary directories under `TMPDIR` with `umask 022`. On HarmonyOS user storage, `mktemp -d` under `umask 077` produced directories that the same shell could not write into.
- Stage `gmp` and `mpfr` headers/libs into the mpc build generators folder on OHOS and skip `.la` files. This avoids libtool following `dependency_libs` from `mpfr` to paths such as `//lib/libgmp.la`.
- Remove installed `libmpc.la` from the package to avoid exporting libtool archive paths to downstream consumers.
- `test_package` injects dependency include directories from the Conan dependency graph because the currently published `gmp` and `mpfr` CMakeDeps data exposes empty include dirs.
