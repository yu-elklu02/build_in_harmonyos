# mozjpeg

Mozilla JPEG encoding/decoding library - an optimized fork of libjpeg-turbo that provides higher compression ratios and better visual quality.

## Description

mozjpeg is a JPEG image codec that provides:
- Superior compression ratios compared to standard JPEG
- Lossless JPEG transcoding
- Progressive JPEG support
- ICC profile handling
- PNG-to-JPEG conversion support (with libpng dependency)
