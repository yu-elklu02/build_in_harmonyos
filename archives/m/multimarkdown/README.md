# MultiMarkdown

## 简介

MultiMarkdown 是 Fletcher T. Penney 开发的轻量级 Markdown 处理器，支持将 Markdown / MultiMarkdown 文档转换为 HTML、LaTeX、OPML、EPUB、OpenDocument 等格式。

## 主要特点

- 支持 MultiMarkdown 扩展语法
- 提供 `multimarkdown` 命令行工具及多个便捷脚本
- 提供 `libMultiMarkdown` C 静态库和公共头文件
- MIT 许可证

## 上游

- 项目主页: https://github.com/fletcher/MultiMarkdown-6
- 版本: 6.6.0

## 使用示例

```bash
printf '*hi*\n' | multimarkdown
multimarkdown --version
```
