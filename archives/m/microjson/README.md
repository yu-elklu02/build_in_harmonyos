# microjson

A tiny JSON parser in C that uses only fixed-extent storage, without using malloc(3).
It is very small and very low-footprint, intended for use in constrained embedded
environments.

- **Source**: https://github.com/Otteri/microjson
- **License**: BSD-2-Clause
- **Author**: Eric S. Raymond
- **Build system**: Makefile (plain make, no configure)
