# arno-iptables-firewall

Single- & multi-homed firewall script with DSL/ADSL support.

## Homepage
https://rocky.eld.leidenuniv.nl/

## License

## Description
Arno's iptables firewall is a firewall script that supports both single-homed
and multi-homed setups. It provides DSL/ADSL support, NAT, logging, traffic
accounting, and various plugins for extended functionality.
