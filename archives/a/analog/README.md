# Analog Web Log Analyzer

Analog 是一款高效的网页日志文件分析器，由 Stephen Turner 开发，现在由 C:Amie 社区维护（Analog CE）。

## 功能特点

- 支持多种日志格式（Apache、IIS 等）
- 输出 HTML、纯文本、XML、LaTeX、PDF 等格式
- 支持图形化统计报告（配合 GD 库）
- 支持压缩日志文件（gzip、bzip2）
- 支持正则表达式过滤（PCRE2）
- 多语言界面
