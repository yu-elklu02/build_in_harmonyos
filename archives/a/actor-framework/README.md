# Actor Framework

The C++ Actor Framework (CAF) is an open-source implementation of the actor
model for building concurrent and distributed systems. This archive packages
CAF 0.17.6 core and I/O libraries for Linux and HarmonyOS PC.

## Packaged version

| Version | Status | Date |
|---------|--------|------|
| 0.17.6 | built | 2026-08-09 |

The default package is static and includes the core and I/O modules. OpenSSL,
OpenCL, Python bindings, examples, and command-line tools are optional upstream
features and are intentionally disabled for this base package.
