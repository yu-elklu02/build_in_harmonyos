# abnfgen for OpenHarmony

`abnfgen` is a command-line generator for documents matching ABNF grammars.

## Package details

- Upstream: https://www.quut.com/abnfgen/
- Build system: GNU Autotools
- Target: OpenHarmony/HarmonyOS aarch64
- Runtime dependencies: none
