# adapta-gtk

An adaptive Gtk+ theme based on Material Design Guidelines.

- 上游项目：https://github.com/adapta-project/adapta-gtk-theme（tag 3.95.0.11）
- 许可证：GPL-2.0 + CC-BY-SA-4.0
- 类型：GTK2/GTK3 主题数据包

安装后提供四个主题变体：Adapta、Adapta-Nokto、Adapta-Eta、Adapta-Nokto-Eta，
位于 `share/themes/`，GTK 桌面通过 `index.theme` 的 `GtkTheme=` 字段解析。

详细适配说明见 [3.95.0.11/notes.md](3.95.0.11/notes.md)。
