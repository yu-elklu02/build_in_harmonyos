# adamstark-audiofile

AudioFile is a simple header-only C++ library for reading and writing WAV and
AIFF audio files.

- Upstream: https://github.com/adamstark/AudioFile
- License: MIT
- Build system: CMake
- Package type: header-library

The package installs the upstream `AudioFile.h` header and exposes the CMake
target `AudioFile::AudioFile`.
