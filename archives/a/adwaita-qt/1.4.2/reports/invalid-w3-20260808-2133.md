## Technical Failure

The invalid run also exposed a packaging defect after SONAME linker flags were
added for CMake on HarmonyOS:

```text
CMake Error: failed to create symbolic link 'libadwaitaqt6priv.so.1': Permission denied
CMake Error: cmake_symlink_library: System Error: Permission denied
CMake Error: failed to create symbolic link 'libadwaitaqt6priv.so': Permission denied
CMake Error: cmake_symlink_library: System Error: Permission denied
```

Root cause: upstream sets `VERSION ${ADWAITAQT_VERSION} SOVERSION 1` on both
shared library targets. Once the Conan toolchain supplies the missing CMake
SONAME linker contract for HarmonyOS, CMake tries to emit versioned shared
library filenames and symlinks. The target filesystem rejected those symlinks.

Offline correction: keep the SONAME linker contract in the Conan toolchain, add
an upstream-default-on CMake option named `ADWAITAQT_VERSIONED_SHARED_LIBS`, and
set it to `OFF` only for OHOS builds. The next valid W3 must verify that:

- the build produces real unversioned `libadwaitaqt6.so` and
  `libadwaitaqt6priv.so`;
- each installed `.so` has a basename SONAME;
- no `DT_NEEDED` entry contains `/`;
- the Qt style plugin loads through `QT_PLUGIN_PATH` under `conanrun`;
- the full run happens on one atomically FREE authorized device for one exact
  frozen input snapshot.
