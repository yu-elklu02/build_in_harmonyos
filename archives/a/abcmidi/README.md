# abcmidi

abcMIDI is a set of C command-line tools for converting between ABC music
notation, MIDI, and PostScript.

## Upstream

- Homepage: https://ifdo.ca/~seymour/runabc/top.html
- Repository: https://github.com/sshlien/abcmidi
- Build system: CMake

The task-board version `20260609` is packaged from the latest upstream tag
available before that date: `2026.06.06` (`b6571ab0de5e985fe28f4fa6aa6d657b8f89dfa1`).
