# audiofile

Audio File Library provides a C/C++ API for reading and writing common audio
file formats, including WAVE, AIFF, NeXT/Sun AU, and NIST SPHERE.

## HarmonyOS adaptation

- Version `0.3.6` is validated on OHOS `armv8`.
- The recipe uses Autotools and retains the upstream non-FLAC test suite.
- See [`0.3.6/notes.md`](0.3.6/notes.md) for compatibility patches and the
  device-validation command.
