# Adobe Source Han Sans KR (思源黑体韩文版)

## 概述

Adobe Source Han Sans KR 是思源黑体（Source Han Sans）的韩文版本，由 Adobe 与 Google 合作开发（Google 版本名为 Noto Sans CJK KR）。这是一套开源 Pan-CJK 无衬线（Sans-serif）字体，提供从 ExtraLight 到 Heavy 共 7 个字重。

## 功能

- 覆盖韩文（KS X 1001 / KS X 1002）、日文、简体中文及拉丁字符
- 7 个字重：ExtraLight, Light, Normal, Regular, Medium, Bold, Heavy
- OpenType/CFF 格式（OTF）
- 支持 OpenType 特性（locl、calt、liga 等）
- SIL Open Font License 1.1 开源授权

## OHOS 适配说明

- **包类型**：纯数据包（字体文件），无需编译
- **安装路径**：鸿蒙系统字体目录 `/system/fonts/` 或 `/data/fonts/`
- **文件格式**：OTF（OpenType/CFF）字体文件
- **无编译依赖**：仅需下载并解压字体文件

## 依赖关系

- 无编译依赖
- 无运行时依赖（系统字体渲染器原生支持 OTF）
