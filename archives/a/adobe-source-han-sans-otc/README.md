# Adobe Source Han Sans OTC (思源黑体 OpenType Collection 合集)

## 概述

Adobe Source Han Sans OTC 是思源黑体（Source Han Sans）的 OpenType Collection（OTC）合集版本，由 Adobe 与 Google 合作开发。单个 OTC 文件内含简体中文、繁体中文（台湾/香港）、日文、韩文全部语言资源，提供从 ExtraLight 到 Heavy 共 7 个字重。

## 功能

- 覆盖简体中文、繁体中文（台湾/香港）、日文、韩文及拉丁字符
- 7 个字重：ExtraLight, Light, Normal, Regular, Medium, Bold, Heavy
- OpenType Collection 格式（OTC）
- 支持 OpenType 特性（locl、calt、liga 等）
- SIL Open Font License 1.1 开源授权

## OHOS 适配说明

- **包类型**：纯数据包（字体文件），无需编译
- **安装路径**：鸿蒙系统字体目录 `/system/fonts/` 或 `/data/fonts/`
- **文件格式**：OTC（OpenType Collection）字体文件
- **无编译依赖**：仅需下载并解压字体文件

## 依赖关系

- 无编译依赖
- 无运行时依赖（系统字体渲染器原生支持 OTC）
