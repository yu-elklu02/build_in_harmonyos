# adwaita-icon-theme

GNOME's Adwaita icon theme — the default icon theme for GNOME desktop environments.

## Description

A collection of icons used as the basis for GNOME themes. It includes:
- Scalable SVG icons
- Fixed-size PNG icons (16x16, 24x24, 32x32, 48x48, 256x256)
- Symbolic icons
- X11/Xcursor cursor themes with symlinks
- Pkg-config file (adwaita-icon-theme.pc)

## Build System

Meson (data-only project — no C/C++ compilation, only data installation)
