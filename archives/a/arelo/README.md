# Arelo

Live reload command-line tool — restart commands when files change.

- Website: https://github.com/makiuchi-d/arelo
- Source: https://github.com/makiuchi-d/arelo
- License: MIT
- Build system: Go
- Category: CLI tool / file watcher

## Description

Arelo is a simple auto-reload (live reload) command-line tool written in Go.
It watches files matching a pattern and restarts the specified command when changes are detected.
Useful for development workflows where you want automatic rebuilding/restarting on file changes.
