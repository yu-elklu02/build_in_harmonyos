# pcalc — Programmer's Calculator

pcalc 是一个程序员命令行计算器，支持十六进制、十进制、八进制、二进制混合运算。

## 功能特性

- 完整的数学解析器，支持括号、加减乘除、指数运算
- 自动在 HEX/DEC/OCT/BIN 之间转换
- 支持在同一表达式中混合不同进制
- 可定义变量
- 内置数学常量（E、PI 等）
- 内置数学函数（sin/cos/sqrt 等）

## 进制表示

| 进制 | 前缀 | 示例 |
|------|------|------|
| 十六进制 | `0x` | `0x1234` |
| 八进制 | `0c` 或 `0o` | `0c1234` |
| 二进制 | `0y` | `0y0101` |
| 十进制 | 无 | `123456` |

## 内置函数

- 数学函数：`sin`, `cos`, `atan`, `log`, `log10`, `exp`, `sqrt`, `int`, `abs`
- 温度转换：`f2c`（华氏→摄氏）, `c2f`（摄氏→华氏）
- 长度转换：`in2mm`（英寸→毫米）, `mm2in`（毫米→英寸）
- 质量转换：`po2kg`（磅→千克）, `kg2po`（千克→磅）

## 使用示例

```bash
# 十六进制计算
pcalc 0x300
# 输出: 768  0x300  0y1100000000

# 混合进制运算
pcalc '0x300 + 3 * 3'
# 输出: 777  0x309  0y1100001001

# 平方根
pcalc sqrt 2
# 输出: 1.4142136  0x1  0y1

# 位运算
pcalc '0x12 or 23'
# 输出: 23  0x17  0y10111
```
