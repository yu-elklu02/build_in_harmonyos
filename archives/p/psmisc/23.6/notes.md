# Notes — psmisc 23.6

## Adaptation Summary

psmisc 23.6 was adapted for HarmonyOS PC aarch64 platform. The package provides
process management utilities: pstree, killall, fuser, peekfd, prtstat, pslog.

## Build Approach

The GitLab tag archive (`psmisc-v23.6.tar.gz`) does NOT include a pre-generated
`configure` script. The CI environment lacks `automake`, so the autotools bootstrap
(`autogen.sh`) cannot run in CI. The conanfile.py builds the six binaries directly
with the compiler, bypassing autotools entirely.

A pre-generated `config.h` is included as a patch (`0001-add-config-h.patch`) so the
source compiles without running configure. The config.h was generated by running
configure locally on the HarmonyOS device.

## Dependencies

- **ncurses/6.6**: Static library from conan artifact repo. pstree links with
  `-lncursesw` (wide-character ncurses). The conan package provides `libncursesw.a`.

## HMDFS Workarounds

1. **umask 022**: HMDFS doesn't allow file creation in directories with 0700
   permissions (which is what `umask 077` creates). Setting `umask 022` fixes this.
2. **config.guess**: Does not recognize HarmonyOS. Patched to map HarmonyOS to
   Linux in the UNAME_SYSTEM case.

## Binaries

| Binary | Sources | Notes |
|--------|---------|-------|
| killall | killall.c, signals.c | Basic process killer |
| fuser | fuser.c, signals.c, statx.c | File user identification (statx.c for statn/fstatn) |
| pstree | pstree.c | Tree display, links with ncurses |
| pslog | pslog.c | Log file process listing |
| prtstat | prtstat.c | Process status display |
| peekfd | peekfd.c | File descriptor peeking (ARM64) |

## Knowledge Learned

- GitLab tag archives lack pre-generated configure script
- HMDFS requires umask 022 for directory writes
- config.guess does not recognize HarmonyOS platform
- ncurses conan package provides libncursesw.a (not libncurses.a)
- fuser requires statx.c when HAVE_DECL_SYS_STATX is defined

## COMPLETED

All 6 binaries compiled and tested successfully on HarmonyOS PC aarch64.
