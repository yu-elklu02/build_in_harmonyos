# potrace

A tool for tracing a bitmap, which means transforming a bitmap into a smooth,
scalable image. The resulting path is a set of polygons (paths) that approximate
the original bitmap image.

## Components

- **potrace**: command-line tool for tracing bitmaps
- **mkbitmap**: command-line tool for scaling and filtering bitmaps
- **libpotrace**: library for programmatic bitmap tracing
