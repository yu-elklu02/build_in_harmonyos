# paho.mqtt.c

Eclipse Paho C client library for MQTT protocol.

Provides synchronous (MQTTClient) and asynchronous (MQTTAsync) MQTT client APIs.

| Version | Status | Notes |
|---------|--------|-------|
| 1.3.14 | built | No SSL, static + shared |
