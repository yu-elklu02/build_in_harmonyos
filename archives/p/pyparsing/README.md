# pyparsing — Python parsing library

pyparsing 是一个纯 Python 实现的解析库，用于构建自定义解析器。
它是 dot2tex 的核心依赖，用于解析 DOT 语法。

## 用途

- 解析 DOT 语法（Graphviz）
- 构建自定义 DSL（领域特定语言）
- 替代 lex/yacc 等传统解析工具
- 纯 Python 实现，易于集成和调试

## 安装

```bash
pip3 install pyparsing
```
