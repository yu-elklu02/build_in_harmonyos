## 构建步骤

上游 Makefile 通过 ocamlfind/ocamlmklib 构建：
1. `make -j1 default opt`：
   - `default` 目标构建 bytecode 归档 `cf.cma`（依赖 `libcf.a dllcf.so` + 各 `.cmi/.cmo`）
   - `opt` 目标构建 native 归档 `cf.cmxa cf.a`
   - 同时 `default:: $(TEST_PROGRAMS)` 链接上游自测程序 `t.cf`
2. `make install`：通过 `ocamlfind install cf` 将 `.mli/.cmi/_p.h/cma/libcf.a/dllcf.so/META` 安装到 `$(OCAMLFIND_DESTDIR)/cf/`
3. Staging 隔离：设 `OCAMLFIND_DESTDIR=<build>/stage/ocamlfind`，再 `copy` 到 `package_folder/lib/cf`

## 上游测试套件

- 测试源: `t/t_cf.ml`（52014 字节，1669 行）
- 测试框架: TAP 风格，`main ()` 收集 `[T1.test; T2.test; ...; T13.test]` 共 13 个测试函数，打印 `1..13`，每个通过的用例打印 `ok N`，失败打印 `not ok N (Failure "...")`
- 执行命令: `make -j1 test test.opt`（bytecode + native 两次运行）
- Makefile `test`/`test.opt` 目标遍历 `t.cf`/`t-opt.cf`，设 `CAML_LD_LIBRARY_PATH=.` 后运行
- 测试内容: Cf_rbtree.Map/Set 函子（插入/查找/删除/size）、Cf_seq（of_list/fold/length/to_list）、Cf_deque（push/pop/empty/fold）、Cf_dfa/Cf_regex/Cf_parser 等核心数据结构与解析器

## test_package

- 测试源: `test_package/t_pagodacf.ml`
- 编译命令: `ocamlfind ocamlc -package cf -linkpkg -o t_pagodacf t_pagodacf.ml`
- 运行: `./t_pagodacf`，打印 `1..4` 与 4 个 `ok N`
- 覆盖的 Cf API（均经 `.mli` 校验）：

  - `Cf_deque`：`nil/push/pop/empty/fold`
