# IXWebSocket

Lightweight WebSocket client and server library for C++ with TLS support and very few dependencies (no Boost).

- **Homepage**: https://github.com/machinezone/IXWebSocket
- **License**: BSD-3-Clause
- **Build System**: CMake
- **Language**: C++11

## Versions

| Version | Status | Date |
|---------|--------|------|
| 12.0.1 | built | 2026-07-22 |

## Dependencies

- zlib/1.3.1 (compression)
- openssl/3.5.6 (TLS, optional)
