# git-town

[git-town](https://github.com/git-town/git-town) is a command-line tool that provides branching and workflow support for Git. It helps create, sync, and ship changes efficiently and with minimal merge conflicts.

## OHOS Adaptation

- **Build system**: Go (custom)
- **Version**: 16.4.1
- **License**: MIT
- **Build command**: `go build -ldflags="-s -w"`
- **Dependencies**: None (pure Go, static binary)
