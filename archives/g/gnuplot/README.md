# gnuplot

gnuplot is a portable command-line driven graphing utility for Unix, Windows,
MacOS, and many other platforms. It generates 2D and 3D plots from data and
mathematical functions in a variety of output formats.

This package provides gnuplot built with zero external dependencies:
- Builtin readline (minimal)
- No libgd, cairo, pango, lua, Qt, or wxwidgets
