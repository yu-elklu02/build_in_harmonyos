# rbenv-bundle-exec

rbenv plugin to automatically run bundle exec when needed.

## Overview

rbenv-bundle-exec is a plugin for rbenv that automatically prefixes commands with `bundle exec` when inside a project with a Gemfile. This saves you from typing `bundle exec` manually for every command.
